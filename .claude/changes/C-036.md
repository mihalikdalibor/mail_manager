## Edge cases

- `Big-Old` → stored/shown `big-old` — cli-filter, saved-filters
- bad names (`a b`, `ä`, 41 chars, `""`, a leading `-`) → name text, no Supabase call — cli-filter, saved-filters
- no filter / `'""'` → save empty text; `--body x` alone → valid — cli-filter
- existing name without `--replace` → duplicate text, event failed, no audit — saved-filters, cli-filter
- `--replace` of a missing name → plain save — saved-filters
- 200 rows incl. unreadable → limit text; replace at 200 works — saved-filters, cli-filter
- racing create → 23505 → duplicate — saved-filters (`create conflict`)
- delete: missing → not-found before confirm; no TTY no `--yes` → TTY text before the session; "no" → `Nothing deleted.`, no event — cli-filter
- unreadable `filter_json` → `(can't be read)` in list/show, `--filter` refuses, replace fixes, delete works — cli-filter, cli-search-filter
- malformed name/id rows → skipped and counted — repo, cli-filter
- unprintable filter (`any` node, two bodies) → `(can't be shown as a line)`, usable with `--filter` — print, cli-filter, cli-search-filter
- `--filter` combined over the 50-node limit → unsupported text — cli-search-filter
- empty saved filter → `emptySavedText` (also with typed words); an empty group anywhere inside → `unreadableText`; match-all backstop — cli-search-filter
- hostile stored values (U+202E) never printed; ESC row unreadable — cli-filter
- migration missing → `RepoError` text (unchanged behaviour) — untested
