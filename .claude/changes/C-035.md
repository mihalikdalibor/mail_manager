## Edge cases

- `mm search`, `mm search '""'` → empty text, exit 1, no login — cli `empty`
- `-- -att`, `-att larger:1mb` → filter terms — cli `double dash`, addition
- `older:1y --jsno` → unknown option text — cli `unknown option`
- `subject:faktura 2023` unquoted → two terms; help says a phrase needs `'subject:"faktura 2023"'` — cli addition
- `--body` only → criteria `['body']` + warning; `--body ""`/spaces → body text — cli `empty`, additions
- `--sent` without a date term → same query, suffix still echoed — cli addition
- `--limit 0` → no samples, no sample read — spec `limit 0`, cli addition
- `--folder` missing / Gmail All Mail hidden → their text, exit 1, `search.finish` failed — cli
- every folder fails → first code's text, exit 1; some fail → exit 0 + note + `(couldn't be searched)` row — spec + cli
- > 500,000 candidates → too-many text; connection lost → connection-lost text — spec + cli
- sample expunged / folder reset after the search → counted gone; all gone → the note alone (decided in the gate) — spec, text `every sample gone`, cli
- empty scope → `No mails match.`, exit 0 — spec + cli
- control character anywhere in the filter → refused with the unsupported text before login (M3a schema rule; decided in the gate) — cli; hostile server strings sanitised on screen and JSON — text `sanitised`, cli
